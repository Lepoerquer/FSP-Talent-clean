# Соответствие фронтенда ТЗ и ответам организаторов

Сверка интерфейса с техническим заданием (`task/tz_extracted.md`), ответами конференции (`task/qa-summary-fsp-2026.md`) и ответами офлайн-сессии (`task/parsed_qa_offline.md`). Проверено на работающем стенде с реальным бэкендом.

Обозначения: ✅ реализовано и проверено · 🟡 реализовано частично · ⛔ невозможно без доработки бэкенда (фронтенд не может обойти ограничение API).

## 1. Кабинет кандидата (ТЗ, п. 2.1)

| Требование | Статус | Где / комментарий |
|---|---|---|
| Профиль и резюме вручную | ✅ | «Анкета и резюме», шаг 1 |
| Загрузка PDF с автораспознаванием (ФИО, контакты, стек, грейд, роли, стаж, soft-skills) | ✅ | распознавание в браузере, значения можно править; грейд - как подсказка |
| Автогенерация стандартизированного PDF-профиля | ✅ | «Скачать PDF-профиль» (PDF с QR формирует сервер) |
| Опрос по отрасли и специализации, выбор грейда, тест, категория | ✅ | анкета (направление → специализация → технологии → грейд) → адаптивный тест |
| Регулярные задания от работодателей | ✅ | панель «Задания от работодателей» (получение и отправка решения) |
| Категория и грейд: отрасль, специализация, грейд | ✅ | профиль и обзор |
| История опроса и теста | ✅ | «История тестирования»: попытки, θ, результат; смены грейда |

| Приглашения: вакансия, зарплата, принять/отклонить | ✅ | вилка в рублях с подписью «на руки / до вычета НДФЛ», причина отказа, отзыв контактов |

| Согласия 152-ФЗ, публикация данных | ✅ | раздельные согласия, журнал, отзыв |
| Связь с ID участника ФСП | ✅ | «ФСП ID и достижения» |
| Видит только свои приглашения и отклики | ✅ | обеспечивает сервер |
| Корректная обработка кандидата без истории ФСП | ✅ | нейтральные сообщения, без штрафа |

## 2. Кабинет работодателя

| Требование | Статус | Где / комментарий |
|---|---|---|
| Профиль компании: описание, направление, контакты | 🟡 | название, ИНН, сайт, описание; сервер не хранит отдельные поля «направление» и «контакты» - они указываются в описании |
| Описание потребности (стек, специализация, грейд, команда) | ✅ | свободный текст → разбор → редактируемые параметры |
| Подборка: рекомендованные категории и кандидаты, обоснование | ✅ | категории с числом кандидатов, баллы и объяснения, расчёт по компонентам C, S, E, T, F, A |
| Банк кандидатов с фильтрами | 🟡 | специализация, грейд, формат, город, зарплата, ФСП - строго на клиенте; стек влияет на порядок, так как карточка не содержит навыков |
| Приглашение без привязки к вакансии, статусы | ✅ | отправлено → просмотрено → принято / отклонено / отозвано / истекло |
| Публикация и редактирование вакансий, входящие отклики | ⛔ | на сервере нет списка, изменения и откликов вакансий |
| Контакты скрыты до принятия | ✅ | |

## 4. Решения конференции и офлайн-сессии

| Решение | Статус |
|---|---|
| Грейд присваивается только тестом; достижения ФСП влияют на ранжирование внутри категории | ✅ в тексте интерфейса и поведении сервера |
| Кандидат выбирает грейд сам; подсказка по резюме допустима | ✅ |
| Неподтверждённый грейд показывается со статусом и ниже в выдаче | ✅ (на сервере итоговая оценка ×0,8) |
| Провал и переход на уровень ниже без траты попытки; кулдаун | ✅ |
| Экспресс-тест на 3–5 минут, возможность пройти тест самостоятельно | ✅ `/express` без регистрации; экспресс в кабинете |
| Имитация входа через ФСП ID (Keycloak) и альтернативная регистрация по почте | ✅ вход через ФСП ID: шаги OIDC Authorization Code + PKCE, параметры запроса; регистрация по почте |
| Отзыв доступа к контактам (плюс) | ✅ |
| Зарплата gross/net - главное подписать | ✅ |
| Концепция ATS | 🟡 синхронизация вакансии из ATS есть в интерфейсе; бэкенд не сохраняет такую потребность (подбор по ней даёт 404) |
| Защита от фиктивных вакансий (плюс) | ✅ проверка ИНН и метка «ИНН проверен» |
| Задания работодателя: работодатель пишет сам (плюс) | ⛔ создание заданий на стороне работодателя отсутствует в API |
| Чат внутри платформы (плюс) | не реализовано (нет API) |
| Несколько специализаций у одного кандидата (плюс) | не реализовано (одна категория на MVP) |
| Дизайн свободный, шрифты разумные | ✅ палитра ФСП, Montserrat |
| Чужие вакансии не парсить | ✅ витрины чужих вакансий нет |
