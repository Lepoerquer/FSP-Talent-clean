# ADR 001: Выбор стека технологий и архитектурного стиля

## Статус
Принято (Accepted)

## Контекст
Платформа FSP-Talent представляет собой цифровую веб-платформу обратного найма ИТ-специалистов с верифицированным профилем Федерации спортивного программирования (ФСП). Основной фокус проекта (60% критериев оценки хакатона) сосредоточен на:
1. Механике выхода на контакт работодателя с кандидатом с обязательным указанием зарплаты "от-до" в рублях и объяснимым ранжированием (35%).
2. Механике тестирования и категоризации на базе банка семейств заданий, адаптивного алгоритма IRT/CAT, защиты от утечек и валидации (25%).

Сроки хакатона - сжатые, команда состоит из 4 человек (Тимлид/Backend, ML-инженер, Frontend, Продакт/Аналитик). Решение должно развертываться одной командой (`make up`), работать стабильно на VPS с ограниченными ресурсами (до 4-8 Гб RAM) и использовать компоненты исключительно с открытыми разрешительными лицензиями (MIT, Apache 2.0, BSD, PostgreSQL).

## Решение
1. **Архитектурный стиль:** Модульный монолит (Modular Monolith) на базе FastAPI с четко разграниченными доменными контекстами и несколькими вспомогательными легковесными сервисами (Mock-реестр ФСП, изолированный Runner песочницы).
2. **Backend:** Python 3.12, FastAPI, Pydantic v2, SQLAlchemy 2.0 (async/sync), Alembic.
   - *Обоснование:* Высокая скорость разработки, богатая экосистема математических и ML библиотек (NumPy, SciPy, sentence-transformers), поддержка асинхронности и автоматическая генерация OpenAPI.
3. **Frontend:** React 18 / 19, TypeScript, Vite, Mantine UI, TanStack Query, React Router.
   - *Обоснование:* Строгая типизация через кодогенерацию из OpenAPI схемы, готовая библиотека качественных компонентов Mantine с соблюдением требований доступности и палитры ФСП.
4. **База данных:** PostgreSQL 16 с расширением `pgvector`.
   - *Обоснование:* Надежность реляционной модели для транзакционных операций, RBAC и истории статусов, а также векторный поиск для семантического подбора кандидатов по потребностям.
5. **Очередь и кэширование:** Valkey 7 / 8 (полностью открытый BSD-форк Redis, свободный от лицензионных ограничений Redis SSPL/RSAL).
6. **Аутентификация:** Keycloak 24+ (OIDC, OIDC identity brokering для интеграции с ФСП ID) с автономным fallback на внутренний JWT сервис.
7. **Инфраструктура:** Docker, Docker Compose, Caddy (автоматический HTTPS и reverse proxy).

## Последствия
- Позволяет вести параллельную разработку ядра платформы (Р1), алгоритмов IRT/ранжирования (Р2) и интерфейсов (Р3).
- Гарантирует запуск на целевом сервере в пределах бюджета памяти 3–3.5 ГБ.
- Обеспечивает 100% юридическую чистоту лицензий используемых компонентов.
